# Shri Chandrika Singh Social & Cultural Foundation — Brochure

A print-ready **12-page A4 brochure**, themed from the Foundation logo
(deep-red ring, saffron, and the six-colour rainbow accent).

## Files
| File | What it is |
|------|------------|
| `brochure.html` | The brochure source — all text, layout & styling |
| `logo.svg` | The Foundation logo, recreated as crisp print vector |
| `assets/` | Drop your real photos here (see below) |
| `Shri-Chandrika-Singh-Foundation-Brochure.pdf` | The rendered output |
| `render.cmd` | Double-click to re-build the PDF after changing anything |

## Add your real photos (recommended)
Save these into the **`assets/`** folder with these **exact names**, then run `render.cmd`:

| File name | Used on | Image |
|-----------|---------|-------|
| `founder.jpg` | Cover portrait | Photo of Shri Chandrika Singh |
| `gate.jpg` | Page 12 banner | The school / campus gate |
| `trustees.jpg` | *(optional)* | Board / trustee group photo |

Until a photo is added, its frame shows a clean branded placeholder — nothing looks broken.
You can also drop a high-res `logo.png` into `assets/` if you'd rather use the original
artwork than the vector recreation (then change `logo.svg` to `assets/logo.png` in `brochure.html`).
